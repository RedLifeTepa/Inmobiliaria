# JavaScript del proyecto

Los archivos JavaScript se separan por responsabilidad conforme el proyecto crezca:

- `app.js`: comportamiento compartido y flujo visual de la V1.
- `portal/`: catálogo, filtros, mapa y captación pública.
- `rpm/`: dashboard, CRM, propiedades, cobranza y expedientes.
- `services/`: Firebase, WhatsApp, mapas y almacenamiento.
- `components/`: componentes reutilizables de interfaz.
